# Syed Abdul Aleem Ahmad Shah — React Portfolio

A premium, responsive React + Vite portfolio for Syed Abdul Aleem Ahmad Shah.

## Stack
- React + Vite
- React Router
- Framer Motion
- Lucide React
- CSS animations / responsive CSS

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Easy edits
- Profile photo: `public/profile.jpg`
- Certificates: `public/certificates/`
- Projects: `src/data/projects.js`
- Services & skills: `src/data/content.js`
- Main visual system: `src/styles.css`
