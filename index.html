My own product — School management system

BunyadSoft — School Management System

BunyadSoft is a complete school management system I designed, built and launched for schools in Pakistan. It replaces the registers, fee books and paperwork a school runs on with one secure online system: admissions, fees, staff salaries, result cards, class diaries and timetables — used by the office, teachers and parents, each from their own login. I built it end to end: the software, the security hardening, the cloud database and the branding, and it is live today with a working demo any school can try.

  • One-form admissions — a parent and all their children added together, and the parent's login is created automatically
  • Fees, receipts and staff salaries with automatic calculations and one-click printing
  • Board-style result cards — grades, positions and comments, generated straight from the entered marks
  • Easy timetables (class, teacher, master & exam) and class diaries that parents can read from home
  • A parent portal for diary, results and fees — no app to install, works on any phone
  • Built secure: role-based access for every user, brute-force login lockout, encrypted sessions and a cloud PostgreSQL database

Case study — Automation

One workflow replaced hours of manual posting

Zewarly's products used to be promoted by hand: pick a product, copy its details, find the photo, write a caption, post it twice. I connected the store, an AI writer and both social platforms into a single n8n workflow.

  1. 1. WooCommerce product is picked automatically
  2. 2. Details tracked in Google Sheets, data cleaned in JavaScript
  3. 3. Gemini AI writes the caption from the real product data
  4. 4. Published to Facebook & Instagram via Meta APIs

Honest scope

It's a working local automation, not a fictional demo — built on real products, with real problems solved along the way: Meta permissions, expired tokens and API configuration.

Why it matters

The same pattern works for any catalogue business: your products already exist — the automation simply turns them into consistent marketing, every day, without you.
